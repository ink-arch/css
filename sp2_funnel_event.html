4SpecialCustomer 퍼널

생성 → 종료를 하나의 사이클로 보고, 종료를 3가지 유형으로 구분해 기록한다.
이벤트시점기록 데이터
Spawn특수손님 생성 시생성 회차 주문 무기 종류 요구 수량
Complete_DealDeal 버튼으로 조기 완료회차 납품 수량(=요구 수량) 보상 골드
Expire_Full시간 만료 + 전량 납품 (자동 완료)회차 보상 골드(보너스 포함)
Expire_Partial시간 만료 + 부분 납품회차 납품 수량 / 요구 수량 부분 보상 골드

읽는 지표

지표계산
완료율(Complete_Deal + Expire_Full) ÷ Spawn
조기 완료 비율Complete_Deal ÷ 완료 전체 — Deal 버튼 사용성 확인
